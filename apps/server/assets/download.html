知之 CLI

在终端和 Claude Code 里管理任务。安装后运行 zhizhi skill install 让 Agent 学会使用。

macOS / Linux

curl -fsSL __ZHIZHI_BASE_URL__/install.sh | sh

装到 ~/.local/bin/zhizhi，可用 ZHIZHI_BIN_DIR 改目录。

Windows（PowerShell）

irm __ZHIZHI_BASE_URL__/install.ps1 | iex

装到 %LOCALAPPDATA%\zhizhi\bin 并加入用户 PATH。

接进来

zhizhi login --url __ZHIZHI_BASE_URL__ --token <令牌> --workspace <工作区>
zhizhi skill install

令牌在 Web 的「设置 › 访问令牌」创建，或跟着「接入 CLI」向导一步步来。
